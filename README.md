# Sean Matthew Capistrano Portfolio

Responsive full-stack developer portfolio built with Express, HTML, CSS, and vanilla JavaScript.

## Run locally

```bash
npm install
npm start
```

Open http://localhost:3000.

## Highlights

- Dark/light theme toggle
- Responsive desktop and mobile navigation
- Resume-backed tech stack and experience sections
- Project case-study modals with local screenshots
- Email, phone, LinkedIn, and Messenger contact links
